# Estimate trait heritability

Last updated on: 2026-10-27

`ldsc h2` estimates one trait's SNP heritability from curated summary statistics and an ordinary unpartitioned LD-score directory. Prepare those inputs with [munge-sumstats](../../user-guide/workflows/munge-sumstats.md) and [ldscore](ldscore.md), or [convert a legacy LD-score suite](../utility-functionalities/convert-ldsc2-ldscores.md). Regression also accepts compatible legacy `.sumstats(.gz)` directly.

```bash
ldsc h2 \
  --sumstats-file results/trait/sumstats.parquet \
  --ldscore-dir results/unpartitioned_ldscores \
  --output-dir results/trait_h2

ldsc plot --result-dir results/trait_h2
```

Replace the sumstats filename with the trait-named file if munging used `--trait-name`. `h2.tsv` contains `total_h2_obs` and `total_h2_obs_se`. The output also includes the fitted-data bin table and run metadata/log under `diagnostics/`. Plotting reads the saved bins to create an LD Score regression diagnostic; it does not refit. Use [partitioned-h2](partitioned-h2.md) for annotated models.

Coordinate-family summary statistics and LD-score artifacts must declare the same genome build before fitting.
This command has no build override; on disagreement, supply matching upstream artifacts as described in the [genome-build policy](../../reference/snp-identity-and-genome-build.md#genome-build-policy).
Legacy LDSC2 text summary statistics retain their separate rsID-to-panel projection path.

## Convert a saved estimate to liability scale

For a binary trait, use the study's sample case fraction and an appropriate population prevalence. The numbers below are illustrative, not estimates for a particular trait:

```bash
ldsc convert-h2-scale \
  --h2-result-dir results/trait_h2 \
  --samp-prev 0.5 \
  --pop-prev 0.01
```

Conversion writes under `results/trait_h2/postprocessing/liability-scale/` and scales the saved estimate and uncertainty without fitting again. Replace `--pop-prev` with `--pop-prev-range MIN MAX` to evaluate an inclusive prevalence grid. There is no CLI output-directory override. See `ldsc convert-h2-scale --help` and [scale-conversion guidance](../../user-guide/workflows/liability-scale.md).

Sources: `run_h2_from_args` in [regression_runner.py](../../../src/ldsc/regression_runner.py), `H2DirectoryWriter` in [outputs.py](../../../src/ldsc/outputs.py), and `add_convert_h2_scale_arguments` in [h2_scale.py](../../../src/ldsc/h2_scale.py).
